# Brightness Control Ultimate

**Brightness Control Ultimate** is a powerful Windows utility that provides **advanced gamma, brightness, and contrast control** for your monitors. It works seamlessly even in **fullscreen games**, allowing you to override in-game color settings with precision.

---

## Key Features

- Adjust **gamma, brightness, and contrast** per monitor
- Apply settings to **all monitors** at once
- Compatible with **fullscreen** and **borderless** games
- Clean and lightweight **WPF interface**, now written in **C#**
- Designed for **performance and accuracy**

---

## 💳 Pricing & Trial

- Brightness Control Ultimate includes a **free trial** with full functionality.
